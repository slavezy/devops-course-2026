# Git в VS Code и терминале

## Три удобные возможности VS Code

1. **Наглядное сравнение файлов.** В diff видно старую и новую версии, добавленные и удалённые строки. Так проще проверить изменения перед коммитом.
2. **Подготовка коммита через Source Control.** Списки Changes и Staged Changes помогают разделить рабочие правки и содержимое будущего коммита. Можно добавлять в индекс отдельные файлы или выбранные фрагменты.
3. **История рядом с кодом.** Source Control Graph показывает ветки и коммиты, а установленный GitLens помогает узнать, кто и когда менял строку, и перейти к соответствующему коммиту.

## Что удобнее делать в терминале

Интерактивный rebase для объединения и переименования нескольких коммитов удобнее запускать явной командой `git rebase -i HEAD~3`: сразу видны диапазон истории и выбранные действия. Переписывать историю следует в отдельной локальной ветке, с которой не работают другие участники.

Источник: [работа с индексом и коммитами в VS Code](https://code.visualstudio.com/docs/sourcecontrol/staging-commits).
