# Цели на семестр

1. Освоить Docker: написать Dockerfile для учебного Python-приложения, собрать образ и запустить приложение в контейнере.
2. Настроить CI/CD с помощью GitHub Actions: автоматизировать запуск тестов при push и создании Pull Request, а также сборку Docker-образа.
3. Освоить основы Linux и Bash: научиться работать с файлами, правами доступа и процессами, написать Bash-скрипт для запуска проверок учебного проекта.
