# Мой пет-проект

## Идея

Сайт-портфолио, на котором я смогу представить себя, свои навыки и учебные проекты. Посетитель сможет узнать обо мне, посмотреть выполненные работы и найти ссылки для связи.

## Стек

- HTML5 - структура страниц и семантическая разметка.
- CSS3 - оформление, Flexbox/Grid и адаптивная вёрстка.
- JavaScript - интерактивные элементы и фильтрация проектов.
- Git и GitHub - история изменений и работа через Pull Request.

## Основные возможности

1. Раздел «Обо мне» с краткой информацией и навыками.
2. Карточки проектов с описанием, технологиями и ссылкой на репозиторий.
3. Фильтрация проектов по технологиям.
4. Раздел контактов со ссылками на GitHub и электронную почту.
5. Адаптивное отображение на телефоне и компьютере.

## Цель

Научиться создавать адаптивный сайт на HTML, CSS и JavaScript, работать с DOM и событиями, а также вести разработку через отдельные ветки и Pull Request.
